# Experimental Work

This directory holds active and archived experiments that are intentionally
kept outside the runtime surface in `src/`.

- `feed-model-lab/`: archived monolithic training lab, preserved in place.
- `route-key-selector/`: focused associative route-key ownership prototype.
- `self-describing-gray-payload/`: fixed-header Gray payload prototype.
- `route-key-gray-payload/`: combined ownership-plus-decoder prototype.
- `self-describing-gray-payload/`: fixed-header Gray payload prototype.
